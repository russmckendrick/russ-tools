# 🧰 Russ Tools

[russ.tools](https://russ.tools/) is a set of small, focused utilities for people who
work with networks, cloud platforms and certificates. Most processing stays in your
browser, with no accounts, analytics or uploads.

Network lookups necessarily send the queried name or address to the provider named in
that tool: Google or Cloudflare DNS-over-HTTPS, RIPEstat for routing data, and Cloudflare
Worker proxies for WHOIS, SSL analysis and Microsoft tenant discovery. Each tool's linked
documentation states its boundary explicitly.

## Quick start

Visit [russ.tools](https://russ.tools/) — there is nothing to install or sign up for.

Tools that take an input support deep links, so a result can be shared or bookmarked
directly: `/ssl-checker/example.com`, `/subnet-calculator/10.0.0.0/16`, `/jwt/<token>`.
Tools with more state than fits in a path share via a compressed `?config` link
instead.

Anything a tool saves is kept in your browser's local storage and never leaves it.
[`/delete`](https://russ.tools/delete) lists exactly what each tool has stored and
clears it, per tool or all at once.

## Technology

- **[Astro](https://astro.build)** — static shell; every page is prerendered HTML
- **React 19** — one island per tool, hydrated only on pages that need it
- **Tailwind CSS 4** with Radix primitives — the shared component layer in `src/components/ui/`
- **Cloudflare Pages** for hosting, **Cloudflare Workers** for three proxied lookups
- **Vitest** and **Playwright** for unit and deep-link coverage

Design is governed by [`DESIGN.md`](DESIGN.md) in the repo root — colour, type, layout,
shape and components, with the token layer generated from it.

## Development

Requires **Node ≥20** and **pnpm** (the lockfile is `pnpm-lock.yaml`).

```bash
git clone https://github.com/russmckendrick/russ-tools.git
cd russ-tools
pnpm install
pnpm dev
```

| Command | What it does |
|---|---|
| `pnpm dev` | Development server |
| `pnpm build` | Production build → `dist/` |
| `pnpm preview` | Serve the production build |
| `pnpm test` | Vitest suite |
| `pnpm test:e2e` | Playwright deep-link matrix |
| `pnpm lint` | ESLint — zero errors is enforced in CI |
| `pnpm generate:tokens` | Regenerate the design tokens from `DESIGN.md` |
| `pnpm generate:og` | Regenerate the Open Graph cards |
| `pnpm generate:docs` | Regenerate the tool tables in the READMEs |

### Adding a tool

A tool is one folder under `src/tools/<id>/` with a `manifest.mjs`. The manifest
declares the path, category, icon, deep-link params, storage keys and SEO, and
everything else follows from it — the page, the index card, the sitemap entry, the
`_redirects` rules, the Open Graph card and the `/delete` listing. No routing table or
central registry needs editing.
